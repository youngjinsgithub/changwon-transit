## 📊 시나리오 A 알고리즘 개요

5개 지표를 Min-Max 정규화 후 가중치 합산:

```
종합점수 = 교통량(승차량 대리) × 0.30
         + 승차 수요         × 0.30
         + 배차간격(경쟁노선 역산) × 0.20
         + 소외도(65세 이상 비율)  × 0.10
         + 인구 역산              × 0.10
```

- **교통량·수요가 높고** (승객이 많이 몰리는 노선)
- **배차간격이 길고** (경쟁 노선이 적은 지역)
- **고령자 비율이 높은** 지역을 경유할수록 높은 점수
